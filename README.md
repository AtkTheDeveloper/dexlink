## Overview

**DexLink** is a lightweight, offline-first Progressive Web App (PWA) for note-taking, designed to help you create and manage notes directly in your browser—no internet connection required. Your notes are stored safely and privately in your browser storage, accessible anytime and anywhere.

---

## Features

- ✨ **Offline-First:** Works seamlessly without an internet connection.
- 📝 **Easy Note Creation:** Quickly add, view, and edit notes.
- 🔒 **Private Storage:** All notes are stored locally in your browser, ensuring privacy.
- ⚡ **Fast & Lightweight:** Minimal and efficient, loads instantly.
- 📱 **Installable PWA:** Add to your home screen on mobile or desktop for app-like experience.
- ♻️ **No Account Needed:** No sign-ups, logins, or cloud storage—your data stays with you.

## Getting Started

### 1. Install / Use DexLink

- **Web:** Simply open the app in your browser. No installation required!
- **Install as PWA:**  
  - On Chrome/Edge: Click the install button in the address bar.
  - On mobile: Use "Add to Home Screen" from your browser menu.

### 2. Create and Manage Notes

- Click **"New Note"** to start writing.
- Your notes are saved automatically as you type.
- Edit or delete notes anytime.

## Development

### Tech Stack

- **Frontend:** JavaScript / HTML5 / CSS3

### Run Locally

